# Ghost Website

Minimal paper-crafted showcase for **Ghost**, an autonomous Android app that opens WhatsApp, sends messages or scheduled wishes one by one, and closes WhatsApp automatically.

## Two Core Use Cases

1. **Unlimited Broadcasts with Custom `{name}` Without Getting Suspended**: Opens real WhatsApp and sends custom-named messages one by one.
2. **Anniversary, Birthday & Daily Good Morning Messages on Time**: Wakes on schedule and delivers your message. The app never forgets.
